# Rights and attribution

No repository-wide licence was present before the archival work. The only
licence file was located at `keysight_na/LICENSE`; no evidence was found that it
was intended to cover files outside that subtree. It has been returned to that
directory rather than extended to unrelated files. The canonical Keysight
archive retains the same licence.

Other files retain their existing notices, if any. This archival commit does
not add a licence grant to files that previously had none. Consult the file
history and relevant rights holders before reuse.

The pre-archive rflab history records work by Pranav Sanghavi and Jacob Hanni,
and Kevin Bandura is named in `rflab_scripts/contributors.txt`. The dedicated
Keysight repository's history records work by Pranav Sanghavi and Joseph
Shepard.
